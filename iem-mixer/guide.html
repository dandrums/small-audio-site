How it fits together

A show holds everything for one gig or set:

PartWhat it is
TracksUp to five audio files (click, guide vocal, stems) that play in sync.
MixesNamed outputs such as IEM or FOH. Each mix has its own level for every track and goes to the interface outputs you pick.
USB patchWhich interface channel each of IEM Mixer's outputs 1–12 uses.
Input metersWhich interface inputs the L/R meters show.
CuesNamed, coloured markers on the timeline that you can jump to.

The main screen has three setup buttons: Tracks, Interface and Cues. Each opens a setup screen, and Done closes it.

1. Connect your interface

  1. Plug a class-compliant USB audio interface or digital console into your iPhone or iPad. Use a powered hub if the interface needs power.
  2. Open IEM Mixer. The status line beside the show title should show a green dot and your interface's name, followed by Engine running.

Without an interface, IEM Mixer plays through the device's own output, which is useful for building a show on the go.

2. Create a show

  1. Tap New and give the show a name.
  2. Use Save As to copy a show, for example to start a new set from an existing one, and Delete to remove one.
  3. Tap the folder button beside the show title to open Saved shows and switch to another show. The one in use is marked Current.

Changes save as you go, and the last show you used reopens at launch.

3. Add tracks

  1. Tap Tracks, then Add track, and choose an audio file from Files.
  2. Each track card shows the file name, format, sample rate and length. Use the card's buttons to Change track, Rename it, choose a Colour or Delete it.
  3. Repeat for up to five tracks. The header counts them, for example 3 OF 5.
Sample rate mismatch If tracks have different sample rates, Track Setup shows a warning. They will still play, but test the show before you perform. Ideally, export every track at the same rate as your interface.

A track's colour is used for its fader on the performance screen, so pick one that's easy to tell apart, such as red for click.

4. Set up mixes & routing

This is where IEM Mixer earns its name. Tap Interface.

  1. The header shows the connected device and how many outputs it has, e.g. 4 AVAILABLE OUTPUTS.
  2. Tap Add mix. A new mix starts with every track at 50 and no outputs.
  3. Tap Rename and give it a clear name: IEM, FOH, Drums…
  4. Use the channel selectors to choose which outputs the mix goes to. For a stereo in-ear feed, pick two, e.g. 1 and 2. For a mono feed to the desk, pick one.
  5. Add as many mixes as your outputs allow.

A mix only appears on the performance screen once it has at least one output.

Shown in red If a mix uses an output that the connected interface doesn't have, for example output 5 on a 4-output interface, it's shown in red. This is normal when you build a show on one interface and play it on another. Change the outputs, or connect the right hardware.

Restart engine at the bottom restarts audio from scratch. You shouldn't need it, but it's there if audio ever stops responding.

5. USB patch

IEM Mixer has 12 outputs. By default they go to interface channels 1–12. On a large console you may want them somewhere else.

  1. In Interface, find the USB patch card.
  2. For each Out 1…Out 12, choose the interface channel it should use, e.g. 37–48 on a 48-channel console.

Two outputs can't share a channel. If you pick a channel that's already in use, the two outputs swap. The patch is saved with the show.

6. Input meters

The L and R meters on the performance screen show two of your interface's inputs. By default these are inputs 1 and 2.

  1. In Interface, find the Input meters card.
  2. Choose an input for L and one for R, or set R to Off for a single meter.

Meter colours: green for normal level, then yellow, orange, and red near the top. A peak marker holds for a moment, then falls.

7. Cues

  1. Tap Cues. The timeline and Play / Pause are at the bottom.
  2. Play or scrub to a point in the song, then tap Add cue. It's placed at the playhead.
  3. Use the cue card's buttons to Rename it (Intro, Verse, Chorus), Edit time (in MM:SS:hh, hundredths of a second), choose a Colour, or Delete it.

Cues you haven't renamed are numbered by timeline position. If you add a cue before CUE 2, it becomes CUE 2 and the rest move up.

8. Performing

  1. Choose a mix with the mix buttons, e.g. IEM. Each shows the outputs it goes to.
  2. The five faders now set that mix's levels. Switch to FOH and the same faders set the FOH mix. Every mix keeps its own levels.
  3. Press Play. It turns into Pause (orange) while playing.
  4. Tap Show cues for a row of cue buttons, then tap one to jump to it. Hide cues gives the faders the space back.

Landscape puts the faders, meters, timeline and transport on one screen and is recommended on stage.

Listen

Listen lets you hear one mix on its own while you prepare, without changing anything.

  1. Plug headphones or a monitor into outputs 1/2.
  2. Tap Listen and choose a mix. The button turns yellow and shows the mix's name.
  3. While listening, switching mix buttons switches what you hear.
  4. Tap it again and choose Off to go back to normal routing.
Before the show Turn Listen off before you perform, or outputs 1/2 will carry the mix you're listening to.

Show Mode

Show mode runs two Shortcuts that you create, so you can get your device ready for stage in one tap.

  1. Open the Shortcuts app and create a shortcut named exactly IEM Show Mode ON. Add actions such as Set Focus (Do Not Disturb), Set Brightness or Set Auto-Lock.
  2. Create a second shortcut named IEM Show Mode OFF that undoes them.
  3. In IEM Mixer, tap Show mode. Shortcuts runs and returns you to the app. The indicator turns green: Show mode on

Troubleshooting

You seeWhat to do
DisconnectedCheck the cable, hub and interface power. IEM Mixer waits for the interface and carries on when it's back, with tracks still in sync.
Engine stoppedUsually caused by a phone call or another app taking the audio. IEM Mixer tries to restart on its own. If it doesn't, use Restart engine in Interface setup.
A mix button is redIt uses outputs the connected interface doesn't have. See Set up mixes.
“Click INTERFACE to create outputs”No mix has an output yet. See Set up mixes.
Nothing on the metersCheck which inputs are selected under Input meters.
Show Mode does nothingCheck the shortcut names match exactly, including capitals and spaces.
